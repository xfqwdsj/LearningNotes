# 编写学习内容

知识点写作读 [知识点指南](../../../docs/writing/knowledge.md)，课程笔记写作读 [笔记指南](../../../docs/writing/notes.md)。位置与身份查 [内容组织](../../../docs/writing/content.md)，Markdown标记与可见文本的中西文间距查 [语法文档](../../../docs/writing/syntax.md)；实现或修改交互演示组件时使用`create-interactive-demo`。

## 常见误区

- 按教材章节就地撰写原始知识或导入演示组件。知识点及其演示有独立来源，笔记只组织课程上下文并链接或引入；不能把相邻笔记的内容布局当成新内容的契约。
- 所属学科或课程不存在时，直接在代码里加名称或图标。先按 [分类入口指南](../../../docs/writing/taxonomy.md) 建立元数据定义。
- 为不同课程复制同一概念，或误以为文件名必须全站唯一。路径决定知识点身份；移动分类时同步迁移引用，翻译保持相同相对路径，板块身份保持稳定。先查找已有知识点，分清表述差异和概念差异。
- 将正文展示能力都写成JSX，或把局部展示容器当成知识点的语义槽位。按语法文档选择标记，交互组件按演示契约实现。
- 把迁移理解成重新分类任务，按图片位置推断题号，或补写并不存在的判分键。保留任务性质，只建立有依据的作答关联。
- 把可渲染的静态HTML当成演示可交互、把可访问的外链当成私有资源，或在公开正文中引入私有内容。验证实际行为与输出范围。
- 在skill、指南和语法文档中各复制一份契约。方法写在指南，路径与标记规则维护在对应契约文档；文档描述最终用法，不记录改动过程。
