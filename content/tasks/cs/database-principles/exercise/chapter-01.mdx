### 一、选择题


1. ::question{#choice-1 number="1"}

   数据库（DB）、数据库系统（DBS）、数据库管理系统（DBMS）之间的关系是:choice-slot{}。

   :::choices{#options-choice-1 mode="single"}

   - :option[A]{#a} DB包含DBS和DBMS
   - :option[B]{#b} DBMS包含DB和DBS
   - :option[C]{#c} DBS包含DB和DBMS
   - :option[D]{#d} 没有任何关系

   :::

   :::reference

   ::correct{input="options-choice-1" option="c"}

   数据库系统（DBS）由数据库、数据库管理系统、应用系统、硬件、操作系统和用户等组成，因此DBS包含DB和DBMS。A、B把包含方向写反，D则错误地否认了它们之间的联系。

   :::

2. ::question{#choice-2 number="2"}

   数据库系统的核心是:choice-slot{}。

   :::choices{#options-choice-2 mode="single"}

   - :option[A]{#a} 数据模型
   - :option[B]{#b} 数据库管理系统
   - :option[C]{#c} 数据库
   - :option[D]{#d} 数据库管理员

   :::

   :::reference

   ::correct{input="options-choice-2" option="b"}

   数据库系统由数据库、DBMS、应用系统、硬件和用户等组成，其中DBMS承担数据定义、操纵、运行管理和维护等核心功能，因此数据库系统的核心是数据库管理系统。数据库只负责保存数据，应用系统面向业务，数据模型是组织数据的方法，都不能替代DBMS的管理作用。

   :::

3. ::question{#choice-3 number="3"}

   数据独立性是数据库技术的重要特点之一。所谓数据独立性是指:choice-slot{}。

   :::choices{#options-choice-3 mode="single"}

   - :option[A]{#a} 数据与程序独立存放
   - :option[B]{#b} 不同的数据被存放在不同的文件中
   - :option[C]{#c} 不同的数据只能被对应的应用程序所使用
   - :option[D]{#d} 以上三种说法都不对

   :::

   :::reference

   ::correct{input="options-choice-3" option="d"}

   数据独立性指应用程序与数据的逻辑结构、物理存储方式之间可以分别调整，而不必相互重写。A描述存放位置，B描述文件划分，C反而把应用与特定数据绑定；三者都没有说明通过映像保持接口稳定的含义。

   :::

4. ::question{#choice-4 number="4"}

   下列关于数据库的正确叙述是:choice-slot{}。

   :::choices{#options-choice-4 mode="single"}

   - :option[A]{#a} 数据库中只存在数据项之间的联系
   - :option[B]{#b} 数据库的数据项之间和记录之间都存在联系
   - :option[C]{#c} 数据库的数据项之间无联系，记录之间存在联系
   - :option[D]{#d} 数据库的数据项之间和记录之间都不存在联系

   :::

   :::reference

   ::correct{input="options-choice-4" option="b"}

   数据库不仅保存记录的字段值，还表达数据项之间和记录之间的联系。A、C只承认其中一层联系，D则否认数据库的结构化联系，均不成立。

   :::

5. ::question{#choice-5 number="5"}

   在DBMS提供的数据语言中，负责数据的模式定义与数据的物理存取构建的是:choice-slot{}。

   :::choices{#options-choice-5 mode="single"}

   - :option[A]{#a} 数据定义语言
   - :option[B]{#b} 数据转换语言
   - :option[C]{#c} 数据操纵语言
   - :option[D]{#d} 数据控制语言

   :::

   :::reference

   ::correct{input="options-choice-5" option="a"}

   数据定义语言（DDL）用于定义和修改数据库结构，包括模式、表、视图、索引、约束以及相关物理存取结构。数据操纵语言负责检索和更新数据，数据控制语言负责授权等控制操作。

   :::

6. ::question{#choice-6 number="6"}

   数据库系统的三级模式结构中，下列不属于三级模式的是:choice-slot{}。

   :::choices{#options-choice-6 mode="single"}

   - :option[A]{#a} 内模式
   - :option[B]{#b} 抽象模式
   - :option[C]{#c} 外模式
   - :option[D]{#d} 概念模式

   :::

   :::reference

   ::correct{input="options-choice-6" option="b"}

   数据库系统的三级模式是外模式、模式和内模式。概念模式通常就是“模式”，而“抽象模式”不是三级模式的标准名称，因此B不属于三级模式。

   :::

7. ::question{#choice-7 number="7"}

   下面关于数据系统叙述正确的是:choice-slot{}。

   :::choices{#options-choice-7 mode="single"}

   - :option[A]{#a} 数据库系统避免了一切冗余
   - :option[B]{#b} 数据库系统减少了数据冗余
   - :option[C]{#c} 数据库系统比文件系统能管理更多的数据
   - :option[D]{#d} 数据库系统中数据的一致性是指数据类型的一致

   :::

   :::reference

   ::correct{input="options-choice-7" option="b"}

   数据库通过共享和统一管理减少不必要的重复存储，但不能消除一切冗余；适度冗余有时仍用于性能或业务需要。数据库比文件系统更强调结构、共享、独立性和统一控制，而不是只比较能管理的数据量；数据一致性也不等于数据类型一致。

   :::

8. ::question{#choice-8 number="8"}

   下列叙述中，错误的是:choice-slot{}。

   :::choices{#options-choice-8 mode="single"}

   - :option[A]{#a} 数据库技术的根本目标是要解决数据共享的问题
   - :option[B]{#b} 数据库设计是指设计一个能满足用户要求，性能良好的数据库
   - :option[C]{#c} 数据库系统中，数据的物理结构必须与逻辑结构一致
   - :option[D]{#d} 数据库系统是一个独立的系统，但是需要操作系统的支持

   :::

   :::reference

   ::correct{input="options-choice-8" option="c"}

   三级模式和两层映像的目的正是允许逻辑结构与物理结构独立变化，因此“物理结构必须与逻辑结构一致”错误。数据库技术解决共享，数据库设计追求满足需求且性能合理，数据库系统仍需操作系统支持。

   :::

9. ::question{#choice-9 number="9"}

   在数据库的三级模式结构中，描述数据库中全体数据的全局逻辑结构和特征的是:choice-slot{}。

   - :option[B]{#b} 内模式
   - :option[C]{#c} 存储模式

   :::

   :::reference

   模式描述数据库中全体数据的全局逻辑结构和特征；外模式面向具体应用，内模式描述物理存储结构。

   :::

    :::

12. ::question{#choice-12 number="12"}

    :::choices{#options-choice-12 mode="single"}

    :::

13. ::question{#choice-13 number="13"}

    数据库中不仅能够保存数据本身，而且能保存数据之间的相互联系，保证了对数据修改的:choice-slot{}。

    :::choices{#options-choice-13 mode="single"}

    - :option[A]{#a} 独立性

    - :option[C]{#c} 共享性
    - :option[D]{#d} 一致性

    :::

    - :option[B]{#b} 用户程序与DBMS的相互独立
    - :option[C]{#c} 用户的应用程序与存储磁盘上数据的相互独立

16. ::question{#choice-16 number="16"}

    为了保证数据库的逻辑独立性，需要修改的是:choice-slot{}

    :::choices{#options-choice-16 mode="single"}

    - :option[B]{#b} 模式与内模式之间的映射

    - :option[D]{#d} 三级模式

### 三、简答题


24. ::question{#short-1 number="1"}

    简述数据库、数据库管理系统、数据库系统三个概念的含义和联系。

    :::reference

    数据库是按照一定结构存储的数据及其联系的集合；数据库管理系统是用来进行数据库创建与管理的专用软件；数据库系统则是使用数据库来存储数据的信息系统。数据库系统包含数据库管理系统与数据库，而数据库存储数据库系统的数据，数据库的创建与管理由数据库管理系统完成。

    :::

25. ::question{#short-2 number="2"}

    数据库系统包括哪几个主要组成部分？各部分的功能是什么？

    :::reference

    数据库：存储系统数据。
    数据库管理系统：对数据库进行创建、管理与维护。
    操作系统：为应用系统与数据库管理系统及硬件提供支持。
    应用系统：为终端用户提供服务，实现业务功能，收集与呈现数据。
    硬件：存储数据和为软件提供支持。
    用户：终端用户通过应用系统实现业务处理；应用程序员负责编写与维护应用系统；数据库管理员负责管理和维护数据库。

    :::

26. ::question{#short-3 number="3"}

    简述数据库管理系统的主要功能。

    :::reference

    （1）数据定义功能：用来对数据库中的数据对象进行定义。
    （2）数据操纵功能：实现对数据库的基本操作，包括检索、更新（包括插入、修改和删除）等。
    （3）数据库运行管理功能：主要包括数据的安全性控制、数据的完整性控制、并发性控制和数据库的恢复。
    （4）数据库的建立和维护功能：包括数据库的初始数据的装入与数据转换、数据库的转储、恢复、重组织与重构造等。
    （5）数据组织、存储和管理：对数据库中各种数据的组织、存储和管理工作，确定以何种文件结构和存取方式物理地组织这些数据。

    :::

27. ::question{#short-4 number="4"}

    试述数据库三级模式结构，说明三级模式结构的优点是什么。

    :::reference

    数据库系统从内部结构看，可以分为三级模式和两个映像，分别是：
    内模式：表示数据库的物理存储结构，面向存储层，只有一个内模式。
    模式：数据库全体数据的逻辑描述结构，面向表示层，只有一个模式。
    外模式：针对某个子应用系统的数据描述结构，面向应用层，可有多个外模式。
    内模式/模式映像：对模式与内模式的对应关系进行转换与记录。
    模式/外模式映像：对外模式与模式之间对应关系进行转换与记录。
    三级模式结构的主要优点是有利于实现数据库的独立性。

    :::

28. ::question{#short-5 number="5"}

    什么是数据库的数据独立性？它包含哪些内容？

    :::reference

    数据库独立性是对数据本身与数据存储和使用的相互制约关系的描述。独立性分为物理独立性与逻辑独立性，其中物理独立性是指数据本身的描述结构与数据的实际存储位置、存储方式之间的制约关系；逻辑独立性是指数据的描述结构与使用数据的应用系统之间的制约关系。

    :::

29. ::question{#short-6 number="6"}

    数据模型的主要作用是什么？数据库设计过程中主要有哪三类模型？

    :::reference

    数据模型用于表达数据、数据联系和相关约束，是数据库设计的重要工具。设计过程中使用的三类模型分别是：面向信息世界的概念模型、面向计算机世界的逻辑模型和描述数据存储的物理模型。最常用的概念模型是实体联系模型，最常用的逻辑模型是关系模型。

    :::

30. ::question{#short-7 number="7"}

    数据模型的三要素是什么？各有什么功能？

    :::reference

    数据模型三要素是：数据结构、数据操纵、完整性约束。
    数据结构：描述数据及数据之间的联系。
    数据操纵：表达对数据进行的操作及方法。
    完整性约束：对数据及数据变化的要求。

    :::
