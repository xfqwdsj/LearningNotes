## 定义

::section{#definition slot="knowledge.definition"}

数据在网络核心中传输主要有两种交换方式。它们的差别不在传输介质，而在是否为通信双方预留资源。

### 电路交换

电路交换先在通信双方之间建立电路，并在沿途链路上预留相应的传输资源；这些资源可以是共享物理链路中的时隙或频带。

- **独占资源**：通话期间，链路带宽（频率或时隙）被固定分配给用户，其他用户无法使用。
- **三个阶段**：建立连接 → 数据传输 → 释放连接。
- **优缺点**：资源预留后通常避免竞争性排队；但静默期仍占用资源，实际时延还取决于传播和设备处理等因素。
- **典型案例**：传统公共电话交换网（PSTN）。

### 分组交换

分组交换把数据划分为较小的分组进行传输。

- **机制**：存储转发。路由器收到一个分组，先接收分组，再根据转发信息将其送往下一条链路。
- **统计复用**：用户按需占用链路，多路数据动态共享带宽。
- **无连接**：通常不需要预先分配固定资源。
- **优缺点**：线路利用率高，适应突发流量；但存在排队延迟，可能发生丢包。
- **典型案例**：互联网。

两种方式的对比：

| 比较项 | 电路交换 | 分组交换 |
| :--- | :--- | :--- |
| 资源分配 | 通信期间独占固定带宽 | 按需共享，统计复用 |
| 建立过程 | 必须先建立连接 | 通常无需预先分配资源 |
| 延迟 | 预留资源后通常避免竞争性排队 | 可能有排队延迟，随负载变化 |
| 线路利用率 | 低，静默期也占用资源 | 高，适合突发流量 |
| 抗毁性 | 通路中断则通信中断 | 可绕行，但可能丢包 |
| 典型场景 | 电话 | 互联网 |

> [!WARNING]
> 电路交换的“建立连接”与TCP的连接建立不是同一件事。电路交换预留的是沿途的电路资源和带宽，TCP只在两端维护连接状态，中间路由器并不为它保留资源。

## 例子

::section{#examples slot="knowledge.examples"}

:::example{title="为什么互联网采用分组交换"}

网页、消息这类流量是突发的：有时要传很多数据，有时完全静默。若为每个用户预留一条独占通路，静默期间带宽被浪费。分组交换让多路数据按需共享链路，空闲的带宽可以被别人使用，代价是拥塞时分组要在路由器中排队，队列满了就丢包。

:::

## 练习

::problems{#switching-practice}

1. ::question{#circuit-drawback}

   电路交换的主要缺点是什么？

   :::choices{#choice mode="single"}
   - :option[A]{#a} 线路利用率低，静默期也占用资源
   - :option[B]{#b} 延迟不固定，随网络负载波动
   - :option[C]{#c} 必须对每个分组做存储转发
   - :option[D]{#d} 无法保证实时性
   :::

   :::reference
   ::correct{option="a"}

   电路交换为通信双方预留沿途资源，即使一方静默，这些资源也不自动转供其他通信使用。
   :::

2. ::question{#packet-features}

   分组交换具有下列哪些特点？

   :::choices{#choice mode="multiple"}
   - :option[A]{#a} 采用统计复用，用户按需占用链路
   - :option[B]{#b} 可能出现排队延迟和丢包
   - :option[C]{#c} 通信前必须建立一条专用的物理通路
   - :option[D]{#d} 适合突发流量
   :::

   :::reference
   ::correct{option="a"}

   ::correct{option="b"}

   ::correct{option="d"}

   建立专用物理通路是电路交换的做法；分组交换依靠存储转发和统计复用，因此会有排队延迟与丢包的可能。
   :::
