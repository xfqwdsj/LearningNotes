## 定义

::section{#definition slot="knowledge.definition"}

**数据库备份**保存数据库在某一时刻可恢复的副本，是介质故障恢复和灾难恢复的数据基础。

按备份对象，物理备份复制数据文件和日志等物理对象，逻辑备份导出数据库对象和数据。

按数据库在线状态，冷备份在数据库关闭时执行，热备份在读写运行中执行，温备份通常只允许有限读写活动。

按备份范围，完整备份保存全量恢复内容，差异备份保存自上次完整备份以来的变化，增量备份保存自上次完整或增量备份以来的变化。差异备份和增量备份都必须依附完整备份才能构成恢复链。

## 例子

::section{#examples slot="knowledge.examples"}

MySQL的`mysqldump`生成包含结构和数据的SQL文本，可以通过`mysql`客户端还原：

```sh
mysqldump -u root -p teach > teach_backup.sql
mysql -u root -p teach < teach_backup.sql
```

## 时间点恢复

时间点恢复通常先还原备份，再按二进制日志重放指定时间或位置之前的已提交修改。恢复完成后应校验数据，并重新建立新的备份基线。
