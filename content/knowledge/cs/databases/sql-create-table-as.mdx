## 定义

::section{#definition slot="knowledge.definition"}

**由查询结果创建表**使用`CREATE TABLE AS`把查询结果的列定义和数据一次写入新表。它适合保存中间结果或建立派生数据副本，但不会自动复制原表的全部约束和索引。

## 例子

::section{#examples slot="knowledge.examples"}

```sql
CREATE TABLE stusumscore AS
SELECT sno, SUM(score) AS sumscore
FROM sc
GROUP BY sno;
```

若只需要复制查询列结构而不复制数据，可以使用恒假条件：

```sql
CREATE TABLE stuman AS
SELECT *
FROM student
WHERE 1 = 0;
```

## 约束复制

新表通常只继承查询结果需要的列类型，原表的主键、外键、默认值、索引和`CHECK`约束不保证随结构复制。正式数据结构应显式写出`CREATE TABLE`并声明所需约束。
