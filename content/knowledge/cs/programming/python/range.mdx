## 定义

::section{#definition slot="knowledge.definition"}

`range(start, stop, step)`表示从`start`开始、按`step`递增或递减的整数序列，**不包含**`stop`。省略`start`时起点为`0`；省略`step`时步长为`1`；步长不能为零。

`range`对象不是列表，它以紧凑的方式表示序列，需要列表时可以调用`list(range(...))`。步长的方向与起终点不匹配时，结果为空。

## 例子

::section{#examples slot="knowledge.examples"}

`list(range(1, 6, 2))`得到`[1, 3, 5]`；`list(range(5, 0, -2))`得到`[5, 3, 1]`。

1. ::question{#range-list}

   `list(range(1, 6, 2))`的结果是：

   :::choices{#choice mode="single"}
   - :option[A]{#a} `[1, 3, 5]`
   - :option[B]{#b} `[1, 2, 3, 4, 5]`
   - :option[C]{#c} `[1, 3, 5, 7]`
   - :option[D]{#d} `[2, 4, 6]`
   :::

   :::reference
   ::correct{option="a"}

   从`1`开始，到`6`之前，步长`2`，取`1, 3, 5`。
   :::
