## 学习路线

先掌握`SELECT ... FROM ... WHERE ...`的基础结构，再学习排序、限行、内置函数、`LIKE`和空值判断。`NULL`参与普通比较会产生未知结果，是三值逻辑的重点。

聚合查询按“先筛选行、再分组、最后筛选组”的顺序理解。多表查询则需要明确笛卡尔积、内连接、外连接和自连接的保留范围。

子查询部分区分非相关与相关两种执行方式，掌握`ANY`、`ALL`、`EXISTS`和双重`NOT EXISTS`。最后学习子查询在`SELECT`、`FROM`、`HAVING`和DML中的位置。

## 复习要点

- `COUNT(*)`统计行数，`COUNT(column)`忽略空值。
- `WHERE`在分组前筛选行，`HAVING`在分组后筛选组。
- 外连接用于保留未匹配记录，常见于“所有学生”一类统计。
- 相关子查询依赖父查询当前行，可能对外层每一行重新执行。
